LOS DATOS EN ESTE PROYECTO NO SON REALES. Fueron generados con un prompt en ChatGPT.

Este es un proyecto personal que realice para familiarizarme con las herraminetas de SQL Server y Power BI.

Mi tarea fue inspeccionar y limpiar los datos en SQL y despues importarlos a Power BI para analizarlos.

En la carpeta SQL_Queries estan los queries que escribi en SQL para inspeccionar los datos.
En la carpeta Datos estan los archivos con los datos en bruto, mientras que en la carpeta SQL_Views estan los queries de SQL que generan datos limpios.
Los archivos que use en Power BI fueron todos los archivos en la carpeta SQL_Views y los archivos Devoluciones y Productos en la carpeta Datos.
