**LOS DATOS EN ESTE PROYECTO NO SON REALES. Fueron generados con un prompt en ChatGPT.**

Este es un proyecto personal que realicé para familiarizarme con las herramientas de SQL Server y Power BI.

Mi tarea fue inspeccionar y limpiar los datos en SQL y después importarlos a Power BI para analizarlos.

En la carpeta **SQL_Queries** están los queries que escribí en SQL para inspeccionar los datos.

En la carpeta **Datos** están los archivos con los datos en bruto, mientras que en la carpeta **SQL_Views** están los queries de SQL que generan datos limpios.

Los archivos que utilicé en Power BI fueron todos los archivos de la carpeta **SQL_Views**, así como los archivos **Devoluciones** y **Productos** de la carpeta **Datos**.
